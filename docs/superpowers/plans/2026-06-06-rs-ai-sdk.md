# Rust AI SDK Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Rust equivalent of gait's Vercel AI SDK + provider layer — the types, provider trait, Anthropic SSE client, OpenAI-compatible provider, and `stream_text`/`generate_text` functions — as a standalone `gait-rs/` crate inside the existing repo.

**Architecture:** A single Rust crate (`gait-rs/`) with a `gait_ai` library that owns message types, a `Provider` trait, two provider implementations (Anthropic via a hand-rolled SSE client, OpenAI-compatible via `async-openai`), and top-level `stream_text`/`generate_text` functions that mirror the Vercel AI SDK surface. The TS `getSDK(modelString)` pattern becomes a `load_provider(model_str, api_key)` factory that parses `"provider/model-id"` strings.

**Tech Stack:** Rust stable, Tokio, `reqwest` (streaming), `serde`/`serde_json`, `async-openai`, `tokio-stream`, `futures-util`

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]

pub enum Message {

    Assistant { content: AssistantContent },
    Tool { content: Vec<ToolResult> },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(untagged)]
pub enum MessageContent {
    Text(String),
    Parts(Vec<ContentPart>),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(untagged)]
pub enum AssistantContent {
    Text(String),
    Parts(Vec<AssistantPart>),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentPart {
    Text { text: String },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "kebab-case")]
pub enum AssistantPart {
    Text { text: String },
    ToolCall(ToolCall),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToolCall {
    #[serde(rename = "toolCallId")]
    pub tool_call_id: String,
    #[serde(rename = "toolName")]
    pub tool_name: String,
    pub args: serde_json::Value,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToolResult {
    #[serde(rename = "type")]
    pub kind: ToolResultKind,
    #[serde(rename = "toolCallId")]
    pub tool_call_id: String,
    pub result: serde_json::Value,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum ToolResultKind {
    ToolResult,
}

// Tool definition — description + JSON schema + async executor
pub struct ToolDef {
    pub name: String,
    pub description: String,
    pub parameters: serde_json::Value, // JSON Schema object
    pub execute: Box<dyn Fn(serde_json::Value) -> std::pin::Pin<Box<dyn std::future::Future<Output = anyhow::Result<serde_json::Value>> + Send>> + Send + Sync>,
}

impl std::fmt::Debug for ToolDef {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("ToolDef")
            .field("name", &self.name)
            .field("description", &self.description)
            .finish()
    }
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct Usage {
    pub input_tokens: u32,
    pub output_tokens: u32,
}

impl Usage {
    pub fn add(&self, other: &Usage) -> Usage {
        Usage {
            input_tokens: self.input_tokens + other.input_tokens,
            output_tokens: self.output_tokens + other.output_tokens,
        }
    }
}

// Emitted per-step by stream_text, mirrors onStepFinish payload
#[derive(Debug, Clone)]
pub struct StepFinish {
    pub text: String,
    pub tool_calls: Vec<ToolCall>,
    pub tool_results: Vec<ToolResult>,
```

The `Provider` trait is the Rust equivalent of Vercel's `LanguageModel` — an abstraction over any LLM backend.

```rust
use crate::types::{Message, ToolDef, Usage};
use std::pin::Pin;
use futures_util::Stream;

// A chunk of streaming output from the LLM
#[derive(Debug)]
pub enum StreamChunk {
    Text(String),
    ToolCallDelta { tool_call_id: String, tool_name: String, args_delta: String },
    ToolCallComplete { tool_call_id: String, tool_name: String, args: serde_json::Value },
    StepUsage(Usage),
    Done,
}

pub type ChunkStream = Pin<Box<dyn Stream<Item = Result<StreamChunk, ProviderError>> + Send>>;

#[derive(Debug, thiserror::Error)]
pub enum ProviderError {
    #[error("HTTP error {status}: {body}")]
    Http { status: u16, body: String },
    #[error("SSE parse error: {0}")]
    Sse(String),
    #[error("Serialization error: {0}")]
    Json(#[from] serde_json::Error),
    #[error("Network error: {0}")]
    Network(#[from] reqwest::Error),
    #[error("{0}")]
    Other(String),
}

// The core trait every LLM provider implements
#[async_trait::async_trait]
pub trait Provider: Send + Sync {
    // Stream tokens and tool call events for one LLM turn
    async fn stream(
        &self,
        system: &str,
        messages: &[Message],
        tools: &[ToolDef],
    ) -> Result<ChunkStream, ProviderError>;

    fn model_id(&self) -> &str;
}
```

```rust
use serde::{Deserialize, Serialize};

// ── Request ──────────────────────────────────────────────────────────────────

#[derive(Debug, Serialize)]
pub struct AnthropicRequest {
    pub model: String,
    pub max_tokens: u32,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub system: Option<String>,
    pub messages: Vec<AnthropicMessage>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    pub tools: Vec<AnthropicTool>,
    pub stream: bool,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct AnthropicMessage {
    pub role: String,  // "user" | "assistant"
    pub content: AnthropicContent,
}

#[derive(Debug, Serialize, Deserialize)]
#[serde(untagged)]
pub enum AnthropicContent {
    Text(String),
    Blocks(Vec<AnthropicBlock>),
}

#[derive(Debug, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum AnthropicBlock {
    Text { text: String },
    ToolUse { id: String, name: String, input: serde_json::Value },
    ToolResult { tool_use_id: String, content: String },
}

#[derive(Debug, Serialize)]
pub struct AnthropicTool {
    pub name: String,
    pub description: String,
    pub input_schema: serde_json::Value,
}

// ── SSE Events ────────────────────────────────────────────────────────────────

#[derive(Debug, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum AnthropicEvent {
    MessageStart { message: MessageStartData },
    ContentBlockStart { index: u32, content_block: ContentBlock },
    ContentBlockDelta { index: u32, delta: ContentDelta },
    ContentBlockStop { index: u32 },
    MessageDelta { delta: MessageDeltaData, usage: Option<DeltaUsage> },
    MessageStop,
    Ping,
    Error { error: AnthropicErrorData },
}

#[derive(Debug, Deserialize)]
pub struct MessageStartData {
    pub usage: Option<DeltaUsage>,
}

#[derive(Debug, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentBlock {
    Text { text: String },
    ToolUse { id: String, name: String },
}

#[derive(Debug, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentDelta {
    TextDelta { text: String },
    InputJsonDelta { partial_json: String },
}

#[derive(Debug, Deserialize)]
pub struct MessageDeltaData {
    pub stop_reason: Option<String>,
}

#[derive(Debug, Deserialize)]
pub struct DeltaUsage {
    pub input_tokens: Option<u32>,
    pub output_tokens: Option<u32>,
}

#[derive(Debug, Deserialize)]
pub struct AnthropicErrorData {
    #[serde(rename = "type")]
    pub kind: String,
    pub message: String,
}

// ── Conversion: crate::types::Message → AnthropicMessage ─────────────────────

use crate::types::{Message, MessageContent, AssistantContent, AssistantPart};

pub fn to_anthropic_messages(messages: &[Message]) -> Vec<AnthropicMessage> {
    messages.iter().map(|m| match m {
        Message::User { content } => AnthropicMessage {
            role: "user".into(),
            content: match content {
                MessageContent::Text(t) => AnthropicContent::Text(t.clone()),
                MessageContent::Parts(parts) => AnthropicContent::Blocks(
                    parts.iter().map(|p| match p {
                        crate::types::ContentPart::Text { text } =>
                            AnthropicBlock::Text { text: text.clone() },
                    }).collect()
                ),
            },
        },
        Message::Assistant { content } => AnthropicMessage {
            role: "assistant".into(),
            content: match content {
                AssistantContent::Text(t) => AnthropicContent::Text(t.clone()),
                AssistantContent::Parts(parts) => AnthropicContent::Blocks(
                    parts.iter().map(|p| match p {
                        AssistantPart::Text { text } =>
                            AnthropicBlock::Text { text: text.clone() },
                        AssistantPart::ToolCall(tc) =>
                            AnthropicBlock::ToolUse {
                                id: tc.tool_call_id.clone(),
                                name: tc.tool_name.clone(),
                                input: tc.args.clone(),
                            },
                    }).collect()
                ),
            },
        },
        Message::Tool { content } => AnthropicMessage {
            role: "user".into(),
            content: AnthropicContent::Blocks(
                content.iter().map(|tr| AnthropicBlock::ToolResult {
                    tool_use_id: tr.tool_call_id.clone(),
                    content: tr.result.to_string(),
                }).collect()
            ),
        },
    }).collect()
}
```

```rust
use crate::provider::{ProviderError, StreamChunk};
use crate::types::Usage;
use crate::anthropic::types::{AnthropicEvent, ContentBlock, ContentDelta};
use eventsource_stream::Eventsource;
use futures_util::{Stream, StreamExt};
use reqwest::Client;
use std::collections::HashMap;

pub struct SseClient {
    pub(crate) http: Client,
    pub(crate) api_key: String,
}

impl SseClient {
    pub fn new(api_key: String) -> Self {
        Self {
            http: Client::new(),
            api_key,
        }
    }

    pub fn stream_request(
        &self,
        body: serde_json::Value,
    ) -> impl Stream<Item = Result<StreamChunk, ProviderError>> + Send + '_ {
        let http = self.http.clone();
        let api_key = self.api_key.clone();

        async_stream::try_stream! {
            let resp = http
                .post("https://api.anthropic.com/v1/messages")
                .header("x-api-key", &api_key)
                .header("anthropic-version", "2023-06-01")
                .header("content-type", "application/json")
                .json(&body)
                .send()
                .await?;

            if !resp.status().is_success() {
                let status = resp.status().as_u16();
                let body = resp.text().await.unwrap_or_default();
                Err(ProviderError::Http { status, body })?;
                return;
            }

            let mut tool_name_map: HashMap<u32, String> = HashMap::new();
            let mut tool_id_map: HashMap<u32, String> = HashMap::new();
            let mut args_buf: HashMap<u32, String> = HashMap::new();

            let mut stream = resp.bytes_stream().eventsource();

            while let Some(event) = stream.next().await {
                let event = event.map_err(|e| ProviderError::Sse(e.to_string()))?;
                if event.event == "message_stop" { break; }
                if event.data.is_empty() || event.data == "[DONE]" { continue; }

                let parsed: AnthropicEvent = serde_json::from_str(&event.data)?;

                match parsed {
                    // Emit input-token count from the opening message event (C5 fix)
                    AnthropicEvent::MessageStart { message } => {
                        if let Some(u) = message.usage {
                            yield StreamChunk::StepUsage(Usage {
                                input_tokens: u.input_tokens.unwrap_or(0),
                                output_tokens: 0,
                            });
                        }
                    }
                    AnthropicEvent::ContentBlockStart { index, content_block } => {
                        if let ContentBlock::ToolUse { id, name } = content_block {
                            tool_id_map.insert(index, id.clone());
                            tool_name_map.insert(index, name.clone());
                            args_buf.insert(index, String::new());
                            yield StreamChunk::ToolCallDelta {
                                tool_call_id: id,
                                tool_name: name,
                                args_delta: String::new(),
                            };
                        }
                    }
                    AnthropicEvent::ContentBlockDelta { index, delta } => match delta {
                        ContentDelta::TextDelta { text } => {
                            yield StreamChunk::Text(text);
                        }
                        ContentDelta::InputJsonDelta { partial_json } => {
                            if let Some(buf) = args_buf.get_mut(&index) {
                                buf.push_str(&partial_json);
                                let id = tool_id_map.get(&index).cloned().unwrap_or_default();
                                let name = tool_name_map.get(&index).cloned().unwrap_or_default();
                                yield StreamChunk::ToolCallDelta {
                                    tool_call_id: id,
                                    tool_name: name,
                                    args_delta: partial_json,
                                };
                            }
                        }
                    },
                    AnthropicEvent::ContentBlockStop { index } => {
                        if let (Some(id), Some(name), Some(buf)) = (
                            tool_id_map.remove(&index),
                            tool_name_map.remove(&index),
                            args_buf.remove(&index),
                        ) {
                            let args = serde_json::from_str(&buf)
                                .unwrap_or(serde_json::Value::String(buf));
                            yield StreamChunk::ToolCallComplete {
                                tool_call_id: id,
                                tool_name: name,
                                args,
                            };
                        }
                    }
                    AnthropicEvent::MessageDelta { usage: Some(u), .. } => {
                        yield StreamChunk::StepUsage(Usage {
                            input_tokens: u.input_tokens.unwrap_or(0),
                            output_tokens: u.output_tokens.unwrap_or(0),
                        });
                    }
                    AnthropicEvent::MessageStop => { yield StreamChunk::Done; break; }
                    AnthropicEvent::Error { error } => {
                        Err(ProviderError::Sse(error.message))?;
                    }
                    _ => {}
                }
            }
        }
    }
}
```

```rust
    pub api_key: String,
    pub model: String,
    pub base_url: Option<String>,

impl OpenAIProvider {
    pub fn new(api_key: String, model: String, base_url: Option<String>) -> Self {
        Self { api_key, model, base_url }
    }

    fn build_client(&self) -> Client<OpenAIConfig> {
        let mut config = OpenAIConfig::new().with_api_key(&self.api_key);
        if let Some(url) = &self.base_url {
            config = config.with_api_base(url);
        }
        Client::with_config(config)

    fn to_openai_messages(messages: &[Message]) -> Vec<ChatCompletionRequestMessage> {
        messages.iter().flat_map(|m| -> Vec<ChatCompletionRequestMessage> {
            match m {
                Message::User { content } => {
                    let text = match content {
                        MessageContent::Text(t) => t.clone(),
                        MessageContent::Parts(parts) => parts.iter()
                            .filter_map(|p| if let crate::types::ContentPart::Text { text } = p { Some(text.as_str()) } else { None })
                            .collect::<Vec<_>>().join(""),
                    };
                    vec![ChatCompletionRequestMessage::User(
                        ChatCompletionRequestUserMessage {
                            content: ChatCompletionRequestUserMessageContent::Text(text),
                            name: None,
                        }
                    )]
                }
                Message::Assistant { content } => {
                    let (text, tool_calls) = match content {
                        AssistantContent::Text(t) => (Some(t.clone()), vec![]),
                        AssistantContent::Parts(parts) => {
                            let text = parts.iter().find_map(|p| if let AssistantPart::Text { text } = p { Some(text.clone()) } else { None });
                            let tcs: Vec<_> = parts.iter().filter_map(|p| {
                                if let AssistantPart::ToolCall(tc) = p {
                                    Some(ChatCompletionMessageToolCall {
                                        id: tc.tool_call_id.clone(),
                                        r#type: ChatCompletionToolType::Function,
                                        function: FunctionCall {
                                            name: tc.tool_name.clone(),
                                            arguments: tc.args.to_string(),
                                        },
                                    })
                                } else { None }
                            }).collect();
                            (text, tcs)
                        }
                    };
                    // C2 fix: use builder to avoid missing-field compile errors across async-openai versions
                    let mut builder = ChatCompletionRequestAssistantMessageArgs::default();
                    if let Some(t) = text { builder = builder.content(t); }
                    if !tool_calls.is_empty() { builder = builder.tool_calls(tool_calls); }
                    vec![ChatCompletionRequestMessage::Assistant(
                        builder.build().expect("assistant message build")
                    )]
                }
                Message::Tool { content } => {
                    content.iter().map(|tr| {
                        ChatCompletionRequestMessage::Tool(
                            ChatCompletionRequestToolMessage {
                                tool_call_id: tr.tool_call_id.clone(),
                                content: ChatCompletionRequestToolMessageContent::Text(
                                    tr.result.to_string()
                                ),
                            }
                        )
                    }).collect()
                }
            }
        }).collect()
    }
}

#[async_trait::async_trait]
impl Provider for OpenAIProvider {
    async fn stream(
        &self,
        system: &str,
        messages: &[Message],
        tools: &[ToolDef],
    ) -> Result<ChunkStream, ProviderError> {
        let client = self.build_client();

        let mut all_messages = vec![];
        if !system.is_empty() {
            all_messages.push(ChatCompletionRequestMessage::System(
                ChatCompletionRequestSystemMessage { content: system.into(), name: None }
            ));
        }
        all_messages.extend(Self::to_openai_messages(messages));

        let oai_tools: Vec<ChatCompletionTool> = tools.iter().map(|t| ChatCompletionTool {
            r#type: ChatCompletionToolType::Function,
            function: FunctionObject {
                name: t.name.clone(),
                description: Some(t.description.clone()),
                parameters: Some(t.parameters.clone()),
                strict: None,
            },
        }).collect();

        let mut req_builder = CreateChatCompletionRequestArgs::default()
            .model(&self.model)
            .messages(all_messages)
            // C3 fix: request usage in the stream (many OAI-compatible gateways honor this)
            .stream_options(ChatCompletionStreamOptions { include_usage: true });
        if !oai_tools.is_empty() {
            req_builder = req_builder.tools(oai_tools);
        }
        let req = req_builder.build().map_err(|e| ProviderError::Other(e.to_string()))?;

        let mut oai_stream = client.chat().create_stream(req).await
            .map_err(|e| ProviderError::Other(e.to_string()))?;

        let stream = async_stream::try_stream! {
            // C1 fix: key by index (u32), not by id string — id is only present on first chunk
            let mut tool_ids:   std::collections::HashMap<u32, String> = std::collections::HashMap::new();
            let mut tool_names: std::collections::HashMap<u32, String> = std::collections::HashMap::new();
            let mut tool_args:  std::collections::HashMap<u32, String> = std::collections::HashMap::new();

            while let Some(chunk) = oai_stream.next().await {
                let chunk = chunk.map_err(|e| ProviderError::Other(e.to_string()))?;
                for choice in &chunk.choices {
                    if let Some(delta) = &choice.delta.content {
                        yield StreamChunk::Text(delta.clone());
                    }
                    if let Some(tcs) = &choice.delta.tool_calls {
                        for tc_delta in tcs {
                            let idx = tc_delta.index;
                            // id and name only arrive on the first delta for this index
                            if let Some(id) = &tc_delta.id {
                                tool_ids.entry(idx).or_insert_with(|| id.clone());
                            }
                            if let Some(f) = &tc_delta.function {
                                if let Some(name) = &f.name {
                                    tool_names.entry(idx).or_insert_with(|| name.clone());
                                }
                                if let Some(args) = &f.arguments {
                                    tool_args.entry(idx).or_default().push_str(args);
                                    let id   = tool_ids.get(&idx).cloned().unwrap_or_default();
                                    let name = tool_names.get(&idx).cloned().unwrap_or_default();
                                    yield StreamChunk::ToolCallDelta {
                                        tool_call_id: id,
                                        tool_name: name,
                                        args_delta: args.clone(),
                                    };
                                }
                            }
                        }
                    }
                    if matches!(choice.finish_reason, Some(async_openai::types::FinishReason::ToolCalls) | Some(async_openai::types::FinishReason::Stop)) {
                        for (idx, args_str) in &tool_args {
                            let id   = tool_ids.get(idx).cloned().unwrap_or_default();
                            let name = tool_names.get(idx).cloned().unwrap_or_default();
                            let args = serde_json::from_str(args_str)
                                .unwrap_or(serde_json::Value::String(args_str.clone()));
                            yield StreamChunk::ToolCallComplete { tool_call_id: id, tool_name: name, args };
                        }
                        yield StreamChunk::Done;
                    }
                }
                if let Some(usage) = &chunk.usage {
                    yield StreamChunk::StepUsage(Usage {
                        input_tokens: usage.prompt_tokens as u32,
                        output_tokens: usage.completion_tokens as u32,
                    });
                }
            }
        };

        Ok(Box::pin(stream))
    }

    fn model_id(&self) -> &str {
        &self.model
    }
}
```

```rust
use crate::provider::{Provider, ProviderError, StreamChunk};
use crate::types::{Message, ToolDef, ToolCall, ToolResult, ToolResultKind, StepFinish, Usage};
use futures_util::StreamExt;

pub struct StreamTextResult {
    pub text: String,
    pub steps: Vec<StepFinish>,
    pub usage: Usage,
}

pub async fn stream_text(
    provider: &dyn Provider,
    system: &str,
    messages: &[Message],
    tools: &[ToolDef],
) -> Result<StreamTextResult, ProviderError> {
    stream_text_with_callback(provider, system, messages, tools, |_| {}).await
}

pub async fn stream_text_with_callback<F>(
    provider: &dyn Provider,
    system: &str,
    messages: &[Message],
    tools: &[ToolDef],
    mut on_token: F,
) -> Result<StreamTextResult, ProviderError>
where
    F: FnMut(&str),
{
    let mut all_messages: Vec<Message> = messages.to_vec();
    let mut all_steps: Vec<StepFinish> = vec![];
    let mut total_usage = Usage::default();

    // Agentic loop: run until no tool calls remain (mirrors maxSteps in TS)
    for _ in 0..50 {
        let mut chunk_stream = provider.stream(system, &all_messages, tools).await?;

        let mut step_text = String::new();
        let mut step_tool_calls: Vec<ToolCall> = vec![];
        let mut step_usage = Usage::default();
        let mut pending_complete: Vec<ToolCall> = vec![];

        while let Some(chunk) = chunk_stream.next().await {
            match chunk? {
                StreamChunk::Text(t) => {
                    on_token(&t);
                    step_text.push_str(&t);
                }
                StreamChunk::ToolCallComplete { tool_call_id, tool_name, args } => {
                    pending_complete.push(ToolCall { tool_call_id, tool_name, args });
                }
                StreamChunk::StepUsage(u) => {
                    step_usage = step_usage.add(&u);
                    total_usage = total_usage.add(&u);
                }
                StreamChunk::Done => break,
                _ => {}
            }
        }

        step_tool_calls = pending_complete.clone();

        // No tool calls — we're done
        if step_tool_calls.is_empty() {
            all_steps.push(StepFinish {
                text: step_text.clone(),
                tool_calls: vec![],
                tool_results: vec![],
                usage: step_usage,
            });
            return Ok(StreamTextResult {
                text: step_text,
                steps: all_steps,
                usage: total_usage,
            });
        }

        // Execute all tool calls
        let mut tool_results: Vec<ToolResult> = vec![];
        for tc in &step_tool_calls {
            let tool = tools.iter().find(|t| t.name == tc.tool_name);
            let result = match tool {
                Some(t) => (t.execute)(tc.args.clone()).await
                    .map(|v| v)
                    .unwrap_or_else(|e| serde_json::Value::String(format!("error: {e}"))),
                None => serde_json::Value::String(format!("unknown tool: {}", tc.tool_name)),
            };
            tool_results.push(ToolResult {
                kind: ToolResultKind::ToolResult,
                tool_call_id: tc.tool_call_id.clone(),
                result,
            });
        }

        // Append assistant turn with tool calls + tool results turn to messages
        use crate::types::{AssistantContent, AssistantPart};
        let mut assistant_parts: Vec<AssistantPart> = vec![];
        if !step_text.is_empty() {
            assistant_parts.push(AssistantPart::Text { text: step_text.clone() });
        }
        for tc in &step_tool_calls {
            assistant_parts.push(AssistantPart::ToolCall(tc.clone()));
        }
        all_messages.push(Message::Assistant {
            content: AssistantContent::Parts(assistant_parts),
        });
        all_messages.push(Message::Tool { content: tool_results.clone() });

        all_steps.push(StepFinish {
            text: step_text,
            tool_calls: step_tool_calls,
            tool_results,
            usage: step_usage,
        });
    }

    Err(ProviderError::Other("max steps (50) exceeded".into()))
}
```

```rust
fn parse_model_string(s: &str) -> Result<(String, String), FactoryError> {
    let parts: Vec<&str> = s.splitn(2, '/').collect();
    if parts.len() != 2 || parts[0].is_empty() || parts[1].is_empty() {
        return Err(FactoryError::InvalidFormat(s.into()));
    }
    Ok((parts[0].into(), parts[1].into()))
}

fn resolve_api_key(provider_id: &str, explicit: Option<String>) -> Result<String, FactoryError> {
    if let Some(key) = explicit {
        if !key.is_empty() { return Ok(key); }
    }
    let env_var = format!("{}_API_KEY", provider_id.to_uppercase());
    std::env::var(&env_var).map_err(|_| FactoryError::MissingApiKey(provider_id.into(), env_var))
}
```
