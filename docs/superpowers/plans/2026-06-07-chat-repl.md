# gait chat REPL + JSON stdout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current raw stderr output with structured NDJSON on stdout (every transcript event also emitted to stdout, streaming tokens as `text_delta` events), and add a `gait chat` REPL that spawns `gait run` as a subprocess and renders the NDJSON events with ANSI/markdown styling.

**Architecture:** A single `emit_event` function writes the same JSON string to both the transcript file and stdout — one code path, impossible to drift. Streaming text tokens emit `text_delta` events to stdout only (not transcript). The REPL spawns `gait run` as a subprocess, pipes its stdout, and renders each JSON event with `termimad` for markdown and raw ANSI codes for tool-call indicators. `harness.rs` and `spawn_agent.rs` use the existing `append_event` (file-only) since they write to *other* sessions' transcripts and must not pollute stdout.

**Tech Stack:** Rust, `termimad` (markdown → ANSI), `rustyline` (readline + history)

```rust
use termimad::MadSkin;

pub struct Renderer {
    pub line_buf: String,
    skin: MadSkin,
}

impl Renderer {
    pub fn new() -> Self {
        Self {
            line_buf: String::new(),
            skin: MadSkin::default(),
        }
    }

    /// Parse one NDJSON line and render to terminal.
    pub fn handle_line(&mut self, json_line: &str) {
        let Ok(v) = serde_json::from_str::<serde_json::Value>(json_line) else { return };
        match v["type"].as_str() {
            Some("text_delta") => {
                let content = v["content"].as_str().unwrap_or("");
                self.line_buf.push_str(content);
                // Render every complete line through termimad
                while let Some(pos) = self.line_buf.find('\n') {
                    let line = self.line_buf[..pos].to_string();
                    self.line_buf = self.line_buf[pos + 1..].to_string();
                    self.skin.print_text(&line);
                }
            }
            Some("tool_call") => {
                let name = v["name"].as_str().unwrap_or("?");
                // dim gray indicator on stderr so it doesn't mix with the JSON stdout stream
                eprintln!("\x1b[2m  ⟳ {}(…)\x1b[0m", name);
            }
            Some("turn_complete") => {
                self.flush();
            }
            Some("error") => {
                self.flush();
                let msg = v["message"].as_str().unwrap_or("unknown error");
                eprintln!("\x1b[31m[error] {}\x1b[0m", msg);
            }
            _ => {} // session_start, tool_result, etc. — not displayed
        }
    }

    /// Flush any partial line remaining in the buffer.
    pub fn flush(&mut self) {
        if !self.line_buf.is_empty() {
            let line = std::mem::take(&mut self.line_buf);
            self.skin.print_text(&line);
        }
    }
}
```

```rust
use std::io::{BufRead, BufReader};
use std::path::PathBuf;
use std::process::{Command, Stdio};
use rustyline::DefaultEditor;
use rustyline::error::ReadlineError;

pub fn new_session_id() -> String {
    format!("s{}", &uuid::Uuid::new_v4().to_string().replace('-', "")[..8])
}

pub fn run_chat(workspace: PathBuf, codebase: PathBuf) -> anyhow::Result<()> {
    let gait_bin = std::env::current_exe().unwrap_or_else(|_| PathBuf::from("gait"));
    let history_path = dirs_next::data_dir()
        .unwrap_or_else(|| PathBuf::from("."))
        .join("gait/chat_history");

    let mut rl = DefaultEditor::new()?;
    let _ = rl.load_history(&history_path);

    let mut session_id = new_session_id();
    eprintln!("gait  session {}  ctrl+d to exit, /new for fresh session", session_id);

    loop {
        let readline = rl.readline("> ");
        let line = match readline {
            Ok(l) => l,
            Err(ReadlineError::Eof) | Err(ReadlineError::Interrupted) => break,
            Err(e) => return Err(e.into()),
        };

        let line = line.trim().to_string();
        if line.is_empty() { continue; }
        let _ = rl.add_history_entry(&line);

        match line.as_str() {
            "/new" => {
                session_id = new_session_id();
                eprintln!("new session {}", session_id);
                continue;
            }
            "/exit" | "exit" | "quit" => break,
            _ => {}
        }

        let mut child = Command::new(&gait_bin)
            .args([
                "run",
                "--session", &session_id,
                "--task", &line,
                "--workspace", workspace.to_str().unwrap_or("."),
                "--codebase", codebase.to_str().unwrap_or("."),
                "--auto",
            ])
            .stdout(Stdio::piped())
            .stderr(Stdio::inherit())  // show gait's stderr (errors) directly
            .spawn()?;

        let stdout = child.stdout.take().expect("piped stdout");
        let reader = BufReader::new(stdout);
        let mut renderer = crate::render::Renderer::new();

        for json_line in reader.lines() {
            renderer.handle_line(&json_line?);
        }
        renderer.flush();
        println!(); // blank line after each response

        child.wait()?;
    }

    let _ = rl.save_history(&history_path);
    Ok(())
}
```

```rust
fn cmd_chat(argv: &[String]) {
    let mut workspace = std::env::current_dir().unwrap_or_else(|_| PathBuf::from("."));
    let mut codebase_path: Option<PathBuf> = None;

    let mut i = 0;
    while i < argv.len() {
        match argv[i].as_str() {
            "--workspace" => { i += 1; workspace = argv.get(i).map(PathBuf::from).unwrap_or(workspace); }
            "--codebase"  => { i += 1; codebase_path = argv.get(i).map(PathBuf::from); }
            _ => {}
        }
        i += 1;
    }

    let codebase = codebase_path.unwrap_or_else(|| workspace.join("codebase"));

    if let Err(e) = gait_ai::chat::run_chat(workspace, codebase) {
        eprintln!("[gait] error: {}", e);
        std::process::exit(1);
    }
}
```
