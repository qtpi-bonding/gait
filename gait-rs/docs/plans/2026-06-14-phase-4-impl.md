# Phase 4 — Input port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give input the same boundary output got: a `TurnSource` port (currency `event::Body`) with `ArgSource` (CLI) and `ReplSource` (REPL) adapters, and **one `run_loop`** shared by `cmd_run` and the REPL. The primary turn becomes append-then-fold like the reply path already is: the adapter builds the `user_turn` body (with its `UserTurnContext`) and appends it, then `run_turn` folds from the log — symmetric with replies, and the shape Phase 5's `RemoteSource` needs.

**Architecture (Option A, per the spec):** Define `TurnSource`. The loop appends each yielded `event::Body` to the log, then runs `run_turn` with **`task: None`** so it folds from the log (it already does this for Clarify/Inform replies). `caps` (`ResolvedProfile`, not `Clone`) is rebuilt **per turn** via a `TurnDriver` — the CLI calls it once (single-shot), the REPL once per line. Land **4a** (port + `ArgSource` + CLI on `run_loop`, `run_turn` untouched) before **4b** (REPL onto `run_loop`) before **4c** (migrate the workflow caller, then delete `run_turn`'s internal `user_turn` append + `TurnInput.task`). Each step stays green.

**Tech Stack:** Rust, `#[async_trait]`, tokio, `anyhow`. Tests via `cargo test`.

/// Build a `user_turn` event body with the same turn-time `UserTurnContext`
/// `run_turn` computes internally (codebase head hash + dirty files). Computed
/// here so the input adapter can append it before the fold (Option A).
pub fn user_turn_body(repos: &crate::git::Repos, codebase: &std::path::Path, task: String) -> crate::proto::gait::log::v1::event::Body {
    let codebase_hash = repos.codebase.head_hash(codebase);
    let dirty_files = repos.codebase.dirty_files(codebase);
    let ctx = crate::session::transcript::UserTurnContext {
        codebase_hash: Some(codebase_hash),
        codebase_dirty: Some(!dirty_files.is_empty()),
        dirty_files: if dirty_files.is_empty() { None } else { Some(dirty_files) },
        injected_files: None,
    };
    crate::proto::events::user_turn(task, None, Some(&ctx))
}

- [ ] **Step 2:** The driver + loop. **`Session` is NOT `Clone`** (`session_obj.rs:8`) — the loop owns an `Arc<Session>` and clones the `Arc` per turn (the REPL already wraps in `Arc` at `chat.rs:205`; the CLI must too). **`auto`/`max_iter`/`preview_policy` come from `config`/flags/node, NOT from `caps`** — supply them per turn via the driver; **never force `auto: true`** (it gates permissions at `turn.rs:904,912` — forcing it would auto-approve every gated tool on a plain `gait run --task …`). Turn errors/panics are handled by the driver, and **`result`/`after_turn` run only on success**:
```rust
use std::ops::ControlFlow;
use std::sync::Arc;
use crate::port::{input::TurnSource, output::{TurnSink, drive}};
use crate::turn::{TurnInput, TurnResult};

/// Per-turn config the loop can't infer (sourced from `config`/CLI `--auto`,`--max-iter`/
/// node, NOT from `caps`). `auto` MUST be honored, never forced.
pub struct LoopConfig { pub auto: bool, pub max_iter: Option<usize>, pub preview_policy: crate::config::PreviewPolicy }

#[async_trait::async_trait]
pub trait TurnDriver {
    /// Rebuild `caps` for this turn (ResolvedProfile is not Clone).
    async fn caps(&mut self) -> anyhow::Result<crate::profile::ResolvedProfile>;
    /// Per-turn auto/max_iter/preview.
    fn turn_config(&self) -> LoopConfig;
    /// After-turn policy (CLI: Scheduler/Harness; REPL: none). SUCCESS ONLY.
    async fn after_turn(&mut self, _r: &TurnResult) {}
    /// Turn error/panic policy. CLI → `sink.diagnostic(Error,…)` + `Break` (→ exit(1)
    /// after loop, via `sink.failed`); REPL → `eprintln` + `Continue` (return to prompt).
    fn on_turn_error(&mut self, sink: &mut dyn TurnSink, e: anyhow::Error) -> ControlFlow<()>;
}

pub async fn run_loop(
    mut source: impl TurnSource,
    sink: &mut impl TurnSink,
    session: Arc<crate::session::Session>,
    gait_dir: &std::path::Path,
    session_id: &str,
    driver: &mut impl TurnDriver,
) -> anyhow::Result<()> {
    let tx_path = gait_dir.join("sessions").join(session_id).join("log.jsonl");
    while let Some(body) = source.next().await {
        crate::proto::wire::append(&tx_path, body)?;           // append-then-fold
        let caps = driver.caps().await?;
        let cfg = driver.turn_config();
        let (tx, rx) = tokio::sync::mpsc::unbounded_channel();
        let emitter = crate::Recorder::for_session(gait_dir, session_id, tx);
        let input = TurnInput { task: None, auto: cfg.auto, max_iter: cfg.max_iter, preview_policy: cfg.preview_policy };
        let session_owned = session.clone();   // Arc clone
        let handle = tokio::spawn(async move { crate::turn::run_turn(&session_owned, &emitter, caps, input).await });
        sink.begin_turn();                     // default no-op; REPL = builder.begin_turn()
        drive(rx, sink).await;                 // emitter dropped in the task → channel closes
        sink.end_turn();                       // default no-op; REPL = flush + block capture. Runs on success AND error.
        match handle.await {
            Ok(Ok(result)) => { sink.result(&result); driver.after_turn(&result).await; }
            Ok(Err(e))      => { if driver.on_turn_error(sink, e).is_break() { break; } }
            Err(panic)      => { if driver.on_turn_error(sink, anyhow::anyhow!("turn task panicked: {panic}")).is_break() { break; } }
        }
    }
    Ok(())
}
```
Add **default-no-op** `fn begin_turn(&mut self) {}` and `fn end_turn(&mut self) {}` to the `TurnSink` trait (`port/output.rs`) so the loop owns turn lifecycle uniformly (`StdioSink` keeps the no-ops; the REPL sink overrides). `on_turn_error` takes `&mut dyn TurnSink` (the `&mut impl` coerces). **Verify** `StdioSink::diagnostic(Error,…)` sets `self.failed` (`cli/output.rs`) so the post-loop `if sink.failed { exit(1) }` (`run.rs:190`) fires on a turn error — today the CLI calls `exit(1)` directly, so this is the behavior to preserve.

## 4b — REPL on run_loop

**Shared state (the crux — from review M4).** The block-capture (`ViewSignal::TurnDone`) and the interaction/respawn decision both live on the **same** `ReplBuilder`, but `run_loop` takes `source` and `sink` as **separate** `&mut` params (can't alias one object). Resolve by sharing the builder behind `Rc<RefCell<ReplBuilder>>`: both `ReplSink` and `ReplSource` hold a clone of the `Rc`. `run_loop` is awaited directly (not `spawn`ed) in `run_chat`, so it need not be `Send` — `Rc<RefCell<…>>` is fine; the sink/source are only borrowed at disjoint times (`drive` then `next`), so the `RefCell` never double-borrows. (The spawned `run_turn` captures only the `Arc<Session>`+emitter+caps, none of the REPL state.)
