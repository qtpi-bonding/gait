**Goal:** Give the agent a sticky working directory that behaves like a real terminal — `cd` once, subsequent commands run there — implemented as an event so it stays replay-complete.

**Architecture:** A new `Cwd { path }` log event, folded by an `ActiveCwd` last-write-wins projection (default = codebase root), exactly like `ActiveManifest`. The `shell` tool gains an optional `cwd` param: present → resolve + emit a `Cwd` event (it sticks) + run there; absent → refold `ActiveCwd` and run in the current sticky dir. The `<status>` block renders a terminal-style prompt line. No hidden state — cwd lives in the log, so it replays and undoes for free.

**Tech Stack:** Rust; `proto/log.proto` (prost/pbjson, regenerated by `build.rs`), `session/retrace.rs` (Projection trait), `proto/events.rs` + `wire::append`, `tools/shell.rs`, `turn.rs`.

---

## Locked design decisions

- **Mechanism (a):** explicit `cwd` param on the `shell` tool. No dedicated `cd` tool; no parsing of leading `cd` from `cmd`.
- **Refold, not a live cell:** `ActiveCwd` is folded from the log on each shell call — same as every other `Active*`. The log is totally ordered, so "last `Cwd` event wins" is fully resolvable; no CRDT merge.
- **Relative resolves against current cwd** (`cwd:"gait-rs"` then later `cwd:".."` works); absolute used as-is.
- **Nonexistent / non-dir target → error, do NOT emit the event** (a failed `cd` leaves you put).
- **No clamping** to codebase root (shell already runs arbitrary commands; fencing cwd is theater). Default cwd = codebase root.
- **Scope:** per-session (the projection seeds at codebase root for each session; persists across turns within a session; `undo` reverts it because the `Cwd` event is truncated with everything else).

- [ ] **Step 2: Projection** in `retrace.rs` (mirror `ActiveManifest`, but seeded with the codebase root):
```rust
/// Last-write-wins working directory. Seeds at the codebase root; each `Cwd`
/// event overwrites. Folded over the full session (survives compaction).
pub(crate) struct ActiveCwd { pub root: std::path::PathBuf }
impl Projection for ActiveCwd {
    type State = std::path::PathBuf;
    fn seed(&self) -> Self::State { self.root.clone() }
    fn apply(&self, state: &mut Self::State, _ev: &Event, kind: &payload::Kind) {
        if let payload::Kind::Cwd(c) = kind { *state = std::path::PathBuf::from(&c.path); }
    }
}
```

```rust
pub fn active_cwd(events: &[Event], root: &std::path::Path) -> std::path::PathBuf {
    run_projection(&ActiveCwd { root: root.to_path_buf() }, events, &HashMap::new())
}
```

```rust
    let events = crate::session::ingestor::Ingestor::from_session(
        &self.ctx.gait_dir, &self.ctx.session_id).events().unwrap_or_default();
    let current = crate::session::retrace::active_cwd(&events, &self.ctx.codebase_path);

    let run_dir = match params.cwd.as_deref().filter(|s| !s.trim().is_empty()) {
        Some(req) => {
            let p = std::path::Path::new(req);
            let target = if p.is_absolute() { p.to_path_buf() } else { current.join(p) };
            // normalize (resolve .. and symlinks) and validate
            match std::fs::canonicalize(&target) {
                Ok(dir) if dir.is_dir() => {
                    let log = self.ctx.gait_dir.join("sessions")
                        .join(&self.ctx.session_id).join("log.jsonl");
                    let _ = crate::proto::wire::append(&log,
                        crate::proto::events::cwd(&dir.to_string_lossy()));
                    dir
                }
                _ => return Ok(serde_json::json!({
                    "output": format!("cd: no such directory: {}", req),
                    "exit_code": 1, "timed_out": false,
                })),
            }
        }
        None => current,
    };
```
