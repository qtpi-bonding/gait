# Phase 2 — Tools & Hooks Publish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the "one write path" invariant real — tool/hook events (`cwd`, `hook_run`) go through the `Recorder` (commit + publish) instead of `wire::append` (log-only), so they appear live on stderr via the Phase-1 `StdioSink` and in the REPL, not only in the log file.

**Architecture:** Thread `&Recorder` per-call into `Tool::execute` and `Hook::post_tool` (the recorder exists only once the turn starts, after tools are built). Replace the two `wire::append` bypasses (`shell` → `cwd`, `ConfigHook` → `hook_run`) with `rec.record(...)`. No sink/classify change — Phase 1's `classify` already maps these payloads to Trace→stderr.

**Tech Stack:** Rust, tokio, `#[async_trait]` (Tool/Hook are `dyn`-dispatched), prost + pbjson. Tests via `cargo test`.

**Spec:** [`../specs/2026-06-13-phase-2-tools-hooks-publish.md`](../specs/2026-06-13-phase-2-tools-hooks-publish.md). Parent plan: [`2026-06-13-turn-io-architecture.md`](./2026-06-13-turn-io-architecture.md).

**Testing note (from CLAUDE.md):** always redirect to a file then grep:
```bash
cargo test 2>&1 > /tmp/t.txt; echo "exit: $?"; grep "test result\|^error\|FAILED" /tmp/t.txt
```

## Task 1: `Recorder::detached()` — a no-op placeholder Recorder

**Files:** `src/proto/emitter.rs`. A **public** (non-`cfg(test)`) constructor so it's usable from the session-less prod path (`stream.rs`) AND from integration test crates (a `#[cfg(test)]` item is invisible to `tests/*.rs`).
